## Происхождение данных

- **World Bank WDI и Country API** — население, экономика и справочник стран; CC BY 4.0.
- **Palmer Penguins / Palmer Station LTER** — наблюдения за пингвинами; CC0.
- **NOAA GML и Scripps** — ряд среднегодовой концентрации CO₂ Mauna Loa.

Ссылки на первоисточники, даты выгрузок, единицы измерения и пояснения находятся в README каждой темы. Данные о пингвинах описывают исследованную выборку птиц. Значения `null` и пустые измерения означают пропуски, а не нулевые наблюдения.
