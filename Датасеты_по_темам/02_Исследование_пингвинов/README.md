# Исследование пингвинов

## Состав выборки пингвинов

[03_Состав_выборки_пингвинов.json](./03_Состав_выборки_пингвинов.json)

Количество пингвинов видов Adelie, Chinstrap и Gentoo, учтённых исследователями в сезонах 2007/08, 2008/09 и 2009/10. Каждая из девяти строк содержит год начала сезона, вид и число наблюдений. Данные описывают состав изученной выборки птиц.

## Измерения пингвинов

[04_Измерения_пингвинов.csv](./04_Измерения_пингвинов.csv)

344 наблюдения пингвинов Adelie, Chinstrap и Gentoo за 2007–2009 годы. Для каждой птицы указаны вид, остров Biscoe, Dream или Torgersen, пол, год, длина и глубина клюва и длина ласта в миллиметрах, масса тела в граммах. В отдельных измерениях и поле пола есть пропуски.
